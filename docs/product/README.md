# Frontend Showcase 产品文档

状态：**FROZEN**

## 1. 当前产品基线

Frontend Showcase 把同一件前端作品同时作为可体验展品、可拆解课程和可被 AI 发现的参考实现。当前采用的产品边界是 v1：

- [产品定位与受众](./v1/vision-and-audiences.md)
- [能力与用户旅程](./v1/capabilities-and-journeys.md)
- [内容接纳契约](./v1/content-contract.md)
- [范围与非目标](./v1/scope.md)

这些文档定义长期承诺，不把某一时点的馆藏数量或页面布局冻结成产品协议。

## 2. 演进规则

- 增加符合现有协议的新 category、renderer 或 Specimen，不自动产生产品 v2。
- 改变 Catalog 与 item 的责任边界、取消独立运行、改变学习或 AI 发现承诺，属于产品边界变化。
- 产品边界变化应先建立 history 工作单元，再决定修订 v1 或建立新版本。
- 当前馆藏事实、实现细节和测试数量应留在 architecture 或 history，不写成永久产品承诺。
