# 产品定位与受众 v1

状态：**FROZEN**

## 1. 产品命题

前端视觉参考通常停留在截图，代码示例又常脱离真实体验。Frontend Showcase 将可运行页面、设计语言、交互参数、作者源码证据和结构化教学放在同一个稳定资源图中，让“看见、操作、理解、复用”连续发生。

## 2. 核心受众

| 受众 | 主要任务 | 产品应提供的证据 |
| --- | --- | --- |
| 前端学习者 | 理解某种视觉或布局为何成立 | 标注、代码证据、实验、测验、完成标准 |
| 设计与开发人员 | 比较风格、布局和交互方案 | 可浏览馆藏、稳定详情路由、真实响应式展品 |
| 示例作者 | 发布不会污染宿主的复杂前端作品 | 独立 runtime、manifest、控制契约、本地资源 |
| AI 工具 | 从稳定 URL 发现可复现实现上下文 | `llms.txt`、catalog、prompt、manifest、learning、context |
| 维护者 | 判断一个 commit 是否可以交付 | 可执行 schema、分层测试、immutable artifact 和生产 smoke |

## 3. 体验原则

1. 先体验真实作品，再阅读解释；教程不替代展品。
2. 控制必须产生可观察效果，不能成为静态参数清单。
3. 学习材料绑定作者源码，不展示无法验证的伪代码。
4. 同一个 item URL 对人类、测试和 AI 都有完整意义。
5. 隔离和离线可复现性优先于集成便利性。

## 4. 成功定义

用户可以从集合找到一件展品，在 Catalog 中安全操作它，切换到学习视角完成实验和测验，并从同一 item 发现 AI 与机器上下文；该 item 同时能脱离 Catalog 独立加载。
