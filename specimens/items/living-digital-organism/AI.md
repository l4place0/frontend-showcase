# 共生体 · SYMBIOSIS — AI Reproduction Guide

## Objective

制作一个像“活着的数字生物”而非模板的单页 WebGL 体验。核心不确定性是：一个真正由大量可受力粒子构成的实时生命体，能否把光标、点击、滚动、时间与声音统一成一条可感知的反馈链。

## Visual Identity

- 深墨黑空间中悬浮一枚由约 15,000 颗离散发光粒子构成的程序化生命体；轮廓、内部密度和受力位移都能看到独立粒子。
- 主色从酸性黄绿过渡至青色与紫色；界面文字极简、技术化、留白宽阔。
- 超大中文空间排版与生命体互相遮挡，保持电影海报般的前后关系。

## Design Tokens

- `--bg: #05070b`：深空背景。
- `--acid: #c8ff48`：生命信号与交互强调。
- `--cyan: #5df6dc`、`--violet: #9e72ff`：生命体进化后的色谱端点。
- `--organism-intensity`：回聚弹簧、指针牵引与碰撞冲量倍率。
- `--organism-turbulence`：粒子目标位置的微观漂移倍率。
- `--organism-audio-low-gain`：低频对整体呼吸形变幅度的增益。
- `--organism-audio-mid-gain`：中频对整体呼吸速度的增益。
- `--organism-audio-high-gain`：高频对 GPU 点粒径的增益。

## Structure

页面由四个纵向章节组成：起源、感知、记忆、共生。WebGL Canvas 固定在视口中，章节改变粒子目标形态、叶瓣数和颜色，不切换页面或创建多套场景。

## Interaction

- 光标是粒子物理中的移动引力核，速度越快，附近粒子获得的牵引力越强。
- 鼠标左键把屏幕坐标变换到正交相机世界坐标并创建持续扩张的冲击壳层。每颗共生体粒子具有依膜层权重变化的圆形碰撞半径；壳层用前后帧半径形成扫掠区间，接触粒子后才写入径向速度。冲击后聚合弹簧会暂时变软，使粒子先炸开，再逐渐回到目标形态。
- 滚动进度控制目标形态的叶瓣数、中心位置、尺度与配色演化。
- “建立连接”进入下一章节，“重新唤醒”回到起点。
- 声音必须由用户按钮主动开启；“模拟频谱”创建确定性的本地虚拟音轨，用真实 `AnalyserNode` 分离低、中、高频并分别驱动整体呼吸形变、呼吸相位速度与 GPU 点粒径。

## Components

核心组件包括固定 WebGL Canvas、四幕语义化章节、生命状态栏、滚动进度轨、智能光标、频谱控制台、点击冲击提示、建立连接 CTA、声音开关、重新唤醒按钮与 WebGL 能力回退卡。

## Rendering

- 使用本地打包的 Three.js `BufferGeometry`、动态 position attribute 与 `THREE.Points`，不使用外部纹理、字体、CDN 或 API。
- 正常浏览器创建约 15,000 颗确定性粒子，测试和低资源环境降低数量。每颗粒子保存基础角度、归一化半径、随机种子、膜层权重、当前位置和速度，并由膜层权重导出二维圆形碰撞体积。
- 冲击波保存前一帧半径、当前半径和每粒子命中位图。扫掠圆环避免快速波前跨帧穿透，同一粒子对同一波只接受一次冲量；因此从共生体外点击会出现可测量的传播延迟与近侧优先形变。
- CPU 逐帧执行弹簧—阻尼积分：程序化极坐标函数只计算每颗粒子的目标位置，实际位置由速度积分产生，因此点击冲击能真正改变组成生命体的同一批粒子。
- 顶点着色器负责粒径，片元着色器只把每个点绘成有核心与光晕的圆粒子；不再用全屏距离场或雾状填充冒充粒子本体。
- 使用低于或等于 1.35 的设备像素比上限；测试环境进一步降低分辨率。

## Controls

- `intensity`：回聚弹簧、指针牵引与碰撞冲量倍率。
- `turbulence`：粒子目标位置的有机漂移强度。
- `audioLowGain`：低频形变增益；Catalog 百分数会转换成小数系数。
- `audioMidGain`：中频呼吸速度增益；放大频谱对呼吸相位的影响。
- `audioHighGain`：高频粒径增益；放大顶点着色器中的点尺寸响应。

最终验收使用三档固定频谱映射：默认 `7.5 / 50 / 85`，增强 `18 / 140 / 220`，映射上限 `35 / 250 / 400`。第三档只用于观察响应边界，不是默认审美参数；三档共用同一组 LOW、MID、HIGH 采样信号，只改变采样值到视觉结果的映射增益。

## Motion and Sound

尊重 `prefers-reduced-motion`：持续渲染缩减为单帧，点击时直接写入一次可见的静态粒子位移，CSS 循环动画停止。Catalog 暂停消息必须停止物理积分。声音在用户手势后创建 Web Audio 节点，关闭时以渐变增益静音；频谱分析仍可在静音输出下驱动粒子呼吸与亮度。

## Accessibility

Canvas 为装饰并从辅助技术隐藏；四幕叙事使用语义化 section 与标题。所有操作使用原生按钮，具有可见焦点与动态 `aria-label`。WebGL 不可用时显示文字状态卡，叙事仍可阅读。

## Responsive Behavior

窄屏保留完整章节与 WebGL 生命体，缩小圆形 CTA，移除自定义光标和次要坐标；章节说明变为全宽。任何尺寸下不能横向溢出。

## Offline and Isolation

作品在 iframe 与静态直开两种模式独立工作，不读取 Catalog DOM、React Context 或宿主 CSS。所有运行资源均由作品目录与构建产物本地提供。

## Implementation Constraints

- 使用本地打包的 Three.js 和 Web Audio，不使用 CDN、远程字体、图片或运行时 API。
- WebGL 仅负责装饰视觉；核心叙事与操作必须在 Canvas 失败时仍可访问。
- Catalog 控制与暂停状态只通过 Specimen Protocol v1 MessageChannel bridge 接收。
- 不读取宿主页面 DOM、React Context 或全局 CSS，也不申请 Pointer Lock、全屏等未声明权限。

## Avoid

- 不使用全屏 SDF、雾或静态粒子背景冒充生命体；共生体的可见轮廓必须由同一批可受力粒子组成。
- 不把四幕做成四个彼此无关的视觉场景。
- 不自动播放声音，不在用户未交互时创建可听输出。
- 不以高 DPR 和无限粒子数量牺牲帧率。
