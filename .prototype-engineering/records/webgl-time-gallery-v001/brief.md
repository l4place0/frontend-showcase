# Prototype Brief

## Hypothesis

一个完全自包含、由真实 Open Access 画作驱动的 WebGL Specimen，可以在不依赖 Catalog 运行时和外部网络的前提下，让用户顺畅完成“欢迎页→树状艺术史时间轴→第一人称圆厅→画作详情→时间轴”的沉浸式科普闭环，并清晰展示 WebGL 展区相较普通页面样品的交互与空间表达能力。

## Primary user flow

用户进入中文欢迎页，点击“开启旅程”；观察非线性展开的西方艺术史树状时间轴并悬停时期卡片；选择时期进入庄严圆厅；使用 WASD/方向键和鼠标漫游，靠近画作后点击或按 E；在唯一的近全屏详情面板查看原图、双语名称、作者、生卒年、时期、来源与授权；按 Esc 关闭并返回时间轴。

## Success criteria

- Catalog 中出现独立 `webgl` 类别展品，清单声明 WebGL 和 Pointer Lock 权限，构建后可直接打开。
- 覆盖至少 8 个按时间排序的西方艺术时期、20 位画家、50 幅真实画作；每幅均内置本地图像、保留真实宽高比，并在来源清单记录可访问的馆藏 URL 与 CC0/Public Domain 说明。
- 欢迎页构图、树状时间轴、悬停卡、非线性动效、第一人称左右移动语义、单例详情面板、Esc 关闭和返回时间轴符合提示词。
- WebGL 场景使用真实灯光、PBR 材质、阴影、反射/环境映射、AO/泛光/色调映射及可见天空；建筑包含穹顶、藻井、齿饰、壁柱、拱券线脚等真实几何，关键视角无大块纯黑空洞。
- 生产运行过程无外部请求、控制台无未处理错误；构建、组件测试和 E2E 测试通过。

## Fidelity and data mode

高视觉保真、可交互原型；使用本地静态确定性数据。开发阶段通过 Wikimedia Commons API 筛选授权元数据为 Public domain 或 CC0 且有图像的条目，下载 960px JPEG 并固化元数据。运行阶段不访问 API、CDN、远程字体或远程图片。

## Out of scope

- 多人、账号、后端存档、联网检索、音频导览和移动端触控第一人称操控。
- 对每个历史时期重建不同建筑；本原型使用同一万神殿式圆厅，通过时期色温、展签与画作内容切换展览。
- 替代专业艺术史数据库或完整学术目录；文案为科普摘要，来源与授权以馆藏条目为准。
